# LiveKit v0.2.0 发布说明

v0.2.0 是 LiveKit 的第二个公开发布版本。

## 重点变化

- 从 vivo 双文件 Live Photo 扩展到检测链架构。
- 支持标准 JPEG Motion Photo 的识别、播放和动态部分清理。
- 优化首页缩略图加载和下拉刷新体验。
- 优化详情页左右滑动预加载，减少转圈等待。
- 修复滚动日期变化导致首页卡顿的问题。

## 支持格式

当前支持：

- vivo 传统双文件 Live Photo：同目录同名 JPG/JPEG + MP4
- 标准 JPEG Motion Photo：JPG/JPEG 内嵌 Motion Photo metadata 和尾部 MP4

仍在适配：

- HEIC / HEIF 动态照片
- 部分厂商私有 Motion Photo 变体
- 更多 vivo 新机型 Motion Photo 样本

## 下载建议

优先下载：

```text
LiveKit-v0.2.0-arm64-v8a.apk
```

如果无法安装，再下载：

```text
LiveKit-v0.2.0-universal.apk
```

## 安全说明

LiveKit 本地运行，不上传照片。删除和清理操作都需要用户主动确认。

未知或无法安全校验的 Motion Photo 格式不会进入清理流程。
